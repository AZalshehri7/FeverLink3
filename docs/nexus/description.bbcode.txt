[size=5][b]FeverLink3 Multiplayer: play Transport Fever 3 together[/b][/size]

Build, run lines and grow towns together in one shared world, each player in their own game.

[line]

[size=4][b]What you get[/b][/size]

[list]
[*][b]Fully integrated into the game, no launcher.[/b] Start Transport Fever 3 from Steam as usual. Hosting, joining, chat, syncing and updates all live in the game's bottom bar and window. There is no extra program to run.
[*][b]Build together.[/b] Roads, bridges, tunnels, rail, signals, stations, stops, depots, lines and vehicles: what one player builds appears in every game.
[*][b]Your other mods work together too.[/b] Mods that change your world by themselves, such as Auto Line Namer, Auto Color Lines or Auto Assign Terminals, stay in sync: the host's copy makes the change and every game applies it at the same moment, and what you set in such a mod's own window reaches every game (new in 0.2.4; seen with two games on one PC).
[*][b]The full game.[/b] Towns grow, traffic flows, ratings change, exactly as in single player. Nothing is switched off.
[*][b]Easy to join.[/b] Over Steam: no ports, no router settings, no IP addresses. The host sends a join code, the friend pastes it.
[*][b]Always the same world.[/b] The games check each other all the time. If they ever drift apart, everyone gets the host's world back in a few seconds and play goes on.
[*][b]Shared speed, pause and chat.[/b]
[*][b]Encrypted.[/b] Everything between the games is encrypted; the join code works like a password.
[*][b]One-click bug reports.[/b] "Report a problem" collects the logs of every player in the session into one zip on your PC, with personal data removed, ready to attach to a GitHub issue.
[*][b]Updates itself.[/b] At a game start FeverLink3 checks GitHub for a newer version, checks every file's SHA-256, and asks for one restart. Never during a session; can be turned off in Troubleshooting.
[/list]

[line]

[size=4][b]Tested in the real game[/b][/size]

[list]
[*]Two players over the internet through Steam with a join code, in sessions of up to 3.5 hours.
[*]In that 3.5-hour session an automatic repair was needed about once every 40 minutes (about 15 seconds each). Other mods that change the world on their own can add more.
[*]A road stands on both games 1.4 s after the click at game speed x1 and 0.8 s at x4 (two games on one PC, a grown save). The wait is a safety margin: every game builds at the same game step.
[*]Automatic update: an installed 0.2.1 updated itself to 0.2.2.
[*]"Report a problem" made its zip in a real session.
[/list]

[size=4][b]Not yet[/b][/size]

[list]
[*]Terrain editing, ground paint and trees are not shared. The terrain tools are switched off during a session.
[*]Mods that change the world on their own (for example an automatic line namer) cause extra syncs. FeverLink3 names them in a warning; turn their automatic changes off while playing together.
[*]Coming back after a short drop without a reload, and separate companies for each player, are planned.
[/list]

[b]Keep backups of the saves you play with.[/b]

[line]

[size=4][b]Requirements[/b][/size]

[list]
[*]Transport Fever 3 on Steam, Windows 10 or 11 (64-bit). Not for Mac, Linux or consoles.
[*]Steam running and logged in.
[*]Every player needs the same game version and the same FeverLink3 version (an older FeverLink3 is told to update). Made for game builds 40420, 40423 and 40425; on a game build it does not know yet, FeverLink3 switches its hooks off instead of risking your game, says so in the FeverLink3 window, does not host, and the host refuses that player with the reason. A FeverLink3 update follows.
[*]Not compatible with other mods that put their own [b]winhttp.dll[/b] in the game folder.
[/list]

[size=4][b]Install (once per PC)[/b][/size]

[list=1]
[*]Download the main file and extract it (right-click, [b]Extract All[/b]). It holds [b]winhttp.dll[/b], a [b]mods[/b] folder and some text files.
[*]Close the game. In Steam, right-click [b]Transport Fever 3[/b] > [b]Manage[/b] > [b]Browse local files[/b]. A folder opens with [b]TransportFever3.exe[/b] in it.
[*]Copy [b]winhttp.dll[/b] and the [b]mods[/b] folder into that folder. Choose [b]Merge[/b] when Windows asks about the mods folder. [b]winhttp.dll[/b] must sit next to TransportFever3.exe, not inside the mods folder. If Windows says winhttp.dll already exists, stop: another mod uses that file.
[*]Start the game from Steam and activate [b]FeverLink3 Multiplayer[/b] in the mod list when you start or load a game.
[/list]

[b]Host:[/b] click the FeverLink3 icon in the bottom bar > [b]Host a game[/b] > [b]Copy code[/b], send the code to your friend, and press [b]Start the session[/b] when they appear.
[b]Join:[/b] open the FeverLink3 window, paste the code (Ctrl+V) and press [b]Join[/b]. Only join people you trust.

[b]Uninstall:[/b] close the game and delete [b]winhttp.dll[/b] and the folder [b]mods\release\feverlink3[/b] from the game folder.

Full guide: [url=https://github.com/AZalshehri7/FeverLink3/blob/main/docs/PLAYING.md]Playing guide[/url]

[size=4][b]What the DLL is[/b][/size]

[b]winhttp.dll[/b] is a small proxy the game loads from its own folder. It passes the game's normal WinHTTP calls on to Windows and runs the FeverLink3 session: the Steam connection between the games and the in-game controller. It is [b]not code-signed[/b] until 1.0.0, so antivirus software may warn. The SHA-256 of every release is on the GitHub release page. Network use: player-to-player traffic through Steam, and the update check against GitHub's releases (can be turned off). No telemetry, no ads, no account. Details: [url=https://github.com/AZalshehri7/FeverLink3/blob/main/docs/SECURITY_FOR_USERS.md]what FeverLink3 does on your PC[/url].

[size=4][b]How it was made[/b][/size]

FeverLink3 is written in Rust and Lua. Most of the code and documentation was written with an AI assistant (Claude, by Anthropic) under the author's direction; the author decides the design, reviews the changes and tests them in the real game. The full history is public on GitHub.
