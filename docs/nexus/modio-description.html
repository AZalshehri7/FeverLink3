Windows PC only. This mod needs a second file, winhttp.dll, that the Mod Hub cannot install: without it the mod does nothing. Not for PlayStation, Xbox, Mac or Linux.

Several players build in one shared Transport Fever 3 world, each in their own game. Unofficial, beta, free for noncommercial use.

What you get

  • Built into the game, no separate launcher. Hosting, joining, chat, syncing and updates live in the game's bottom bar and window.
  • Build together. Roads, bridges, tunnels, rail, signals, stations, stops, depots, lines and vehicles: what one player builds appears in every game.
  • Your other mods work together too. Mods that change your world by themselves, such as Auto Line Namer, Auto Color Lines or Auto Assign Terminals, stay in sync: the host's copy makes the change and every game applies it at the same moment, and what you set in such a mod's own window reaches every game (new in 0.2.4; seen with two games on one PC).
  • The full game. Towns grow, traffic flows, ratings change, exactly as in single player.
  • Easy to join. Over Steam with a join code: no ports, no router settings, no IP addresses.
  • Always the same world. The games check each other all the time; if they drift apart, everyone gets the host's world back in a few seconds.
  • Shared speed, pause and chat. Encrypted. One-click bug reports.

Install the second file (once per PC)

  1. Download FeverLink3-0.2.10.zip from github.com/AZalshehri7/FeverLink3 (Releases) and extract it.
  2. Close the game. In Steam, right-click Transport Fever 3, Manage, Browse local files. A folder with TransportFever3.exe opens.
  3. Copy winhttp.dll from the zip into that folder, next to TransportFever3.exe (not into a mods folder). If Windows says winhttp.dll already exists, stop: another mod uses that file.
  4. Start the game from Steam and activate FeverLink3 Multiplayer when you start or load a game. Click the FeverLink3 icon in the bottom bar to host or join.

The zip also contains the mod itself (mods folder). If you copy that too, you do not need this Mod Hub version; the game then uses the copy in the game folder. winhttp.dll updates FeverLink3 by itself from GitHub at game start (it can be turned off in the window's Troubleshooting section). It is not code-signed until 1.0.0.

Status

  • Played over the internet with two players through Steam, sessions of up to 3.5 hours, about one automatic repair (about 15 s) every 40 minutes.
  • A build stands on both games 1.4 s after the click at game speed x1, 0.8 s at x4 (two games on one PC).
  • Terrain heights and ground paint are shared (since 0.2.7), and trees, plants and rocks (new in 0.2.8: tell us if the trees look different for someone). Mods that change the world on their own cause extra syncs.

Every player needs the same game version and FeverLink3 version. Keep backups of your saves: this is a beta.
