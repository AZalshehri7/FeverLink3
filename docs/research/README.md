# Research notes

The research behind FeverLink3 (the logs of the test runs, the analyses of the game executable and the comparisons with
other projects that came after the first public release) is **kept private**. The logs and reports are large and they
contain details of the maintainer's machine, so they are not part of this repository.

If you want to read one of them, ask the maintainer and it can be shared with you individually. Open an issue on the
repository and say which topic you are interested in (for example town growth, the checksum lanes or the native hooks).
